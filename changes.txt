Release Notes

Version 5.3.0 (Build - 2026042000)
- Full modernization for Moodle 5.3 and PHP 8.2 - 8.4+.
- Implemented Moodle Privacy API (\privacy\provider) for GDPR compliance.
- Hardened security: decoupled account connection from sesskey, using secure 32-character random tokens.
- Masked site bot token input using admin_setting_configpasswordunmask.
- Added support for Telegram HTML message formatting and direct "Open in Moodle" action links.
- Added message length boundary enforcement to prevent Telegram 4096-character delivery errors.
- Modernized user preferences UI with Bootstrap 5.3 / Boost theme styling.
- Added optional manual Chat ID configuration for users and administrators.
- Added optional working Telegram Webhook receiver endpoint.
- Added automated PHPUnit test suite.
- Replaced legacy telegram.me links with modern t.me links.
- Fixed all PHPCS and Moodle CodeChecker compliance issues.

Version 3.2.5 (Build - 2017071200)
- Released as stable for Moodle 3.2.
